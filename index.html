Claude Code Mods là gì?

Hệ thống plugin cho phép chèn mã JavaScript / TypeScript vào các hook trong lifecycle của Claude Code để can thiệp, mở rộng và tùy biến hành vi của nó.

UI Extensions

Safety Guards

03

Auditing & Telemetry

Ghi lại toàn bộ hành động sửa file và thực thi lệnh của Agent.

04

Workflow Automation

  "version": "1.0.0",
  "description": "Hiển thị dự báo thời tiết cho Context Window Token Usage",
  "author": "Developer Name",
  "main": "src/index.js"

    {
      "event": "ui.render",
      "target": "AbovePrompt",
      "handler": "renderWeatherBar"
    }
  ]

export function calculateWeather(usedTokens, maxTokens) {
  const percentage = (usedTokens / maxTokens) * 100;

  if (percentage < 30) return { status: 'Clear', icon: '☀️', color: 'green' };
  if (percentage < 60) return { status: 'Partly Cloudy', icon: '🌤️', color: 'cyan' };
  if (percentage < 80) return { status: 'Overcast', icon: '☁️', color: 'yellow' };
  if (percentage < 95) return { status: 'Storm Warning', icon: '🌩️', color: 'red' };
  return { status: 'Critical / Compression Required', icon: '🚨', color: 'bgRed' };
}
import { calculateWeather } from './weather-utils.js';

export async function renderWeatherBar(event, $) {
  try {
    const usage = await $.session.usage();
    const usedTokens = usage.inputTokens + usage.outputTokens;
    const maxTokens = usage.contextWindowSize || 200000;

    $.state.lastKnownUsage = { used: usedTokens, max: maxTokens, updatedAt: Date.now() };

    const weather = calculateWeather(usedTokens, maxTokens);
    const pct = ((usedTokens / maxTokens) * 100).toFixed(1);

    return {
      type: 'Text',
      content: `${weather.icon} Token Weather: ${weather.status} (${usedTokens.toLocaleString()} / ${maxTokens.toLocaleString()} - ${pct}%)`,
      style: { color: weather.color, bold: true, dim: pct < 30 }
    };
  } catch (error) {
    return { type: 'Text', content: '⚠️ Token Weather: Unavailable', style: { color: 'gray' } };
  }
}

⚡ Reload tức thì

Mỗi lần lưu file trong thư mục plugin, mã nguồn mới được nạp lại trong vài mili-giây.

🧠 Vì sao cần $.state?

Khi reload, mọi biến toàn cục trong VM bị xóa sạch. $.state được Claude Code giữ bên ngoài sandbox nên dữ liệu vẫn nguyên vẹn.

09 · BEST PRACTICES

4 thói quen vàng khi làm Mod

01

Khai thác Hot-Reload

Chạy claude --plugin-dir . và giữ terminal mở. Feedback loop < 1 giây.

02

Ủy quyền dựng khung

Để Claude sinh cấu trúc và type definition — tránh sai tên hook, sai định dạng manifest.

03

Dùng $.state

Không dùng biến toàn cục — chúng mất sạch khi reload. Lưu dữ liệu biến đổi vào $.state.

04

Fail-safe execution

Bọc try…catch, trả fallback. Một Mod crash không được làm hỏng phiên làm việc.
